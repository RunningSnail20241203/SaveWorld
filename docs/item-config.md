# 物品配置 (Item Config)

> 文档版本: v2.2 | 最后更新: 2026-04-23

## 概述

定义游戏中全部 116 种物品（9 条合成线 × 10 级 + 6 种特殊物品）。

---

## ItemType 枚举

**命名空间**: `SaveWorld.Game.Items`

### ID 编码规则

```
千位 = 生产线编号
个位 = 等级

1001-1010 = 水源 (Water)
2001-2010 = 食物 (Food)
3001-3010 = 工具 (Tool)
4001-4010 = 住所 (Home)
5001-5010 = 医疗 (Medical)
6001-6010 = 能源 (Energy)
7001-7010 = 知识 (Knowledge)
8001-8010 = 希望 (Hope)
9001-9010 = 探索 (Explore)
10001-10006 = 特殊物品
```

## ItemData

```csharp
[Serializable]
public class ItemData
{
    public ItemType itemType;
    public string itemName;      // 显示名称
    public int level;            // 1-10
    public string line;          // 生产线名称
    public string description;   // 描述
}
```

---

## ItemConfig 静态管理器

### 核心方法

```csharp
public static ItemData GetItemData(ItemType itemType)           // 获取物品数据
public static string GetItemName(ItemType itemType)             // 获取名称
public static int GetItemLevel(ItemType itemType)               // 获取等级
public static string GetItemDescription(ItemType itemType)      // 获取描述
public static ItemType GetNextLevelItem(ItemType itemType)      // 获取下一级物品
```

### GetNextLevelItem 规则

```csharp
// 同生产线等级+1
int baseId = ((int)itemType / 1000) * 1000;
int nextLevel = data.level + 1;
int nextItemId = baseId + nextLevel;

// L10 没有下一级 → ItemType.None
```
